# 个人工作与能力提升看板 · 云服务器部署手册

适用环境：Linux 云服务器（Ubuntu 20.04+/CentOS 7+/Debian 11+），域名已解析到服务器 IP（HTTPS 必需）。

## 0. 部署架构

```
用户浏览器 ──HTTPS──> Nginx(443) ──HTTP──> growth-dashboard.jar(7100) ──> H2 文件库 / MySQL
```

- 应用：单个自包含 jar（前端、ECharts、种子数据全部内置）
- 数据库：默认内嵌 H2（免安装）；生产建议 MySQL
- AI：可选，配置 OpenAI 兼容服务后启用大模型能力

---

## 1. 服务器准备

```bash
# Ubuntu / Debian
sudo apt update && sudo apt install -y openjdk-17-jre-headless nginx

# CentOS / Rocky
sudo dnf install -y java-17-openjdk-headless nginx

# 验证
java -version   # 应显示 17.x
```

## 2. 上传应用

本地构建产物：`growth-dashboard/target/growth-dashboard-1.0.0.jar`

```bash
# 本地执行（Windows Git Bash）
scp target/growth-dashboard-1.0.0.jar user@<服务器IP>:/home/user/

# 服务器上建立目录
sudo mkdir -p /opt/growth-dashboard
sudo mv /home/user/growth-dashboard-1.0.0.jar /opt/growth-dashboard/
sudo useradd -r -s /sbin/nologin dashboard   # 专用低权限用户
sudo chown -R dashboard:dashboard /opt/growth-dashboard
```

## 3. 数据库（二选一）

### 方案 A：内嵌 H2（默认，零配置）

无需任何操作。首次启动自动建库，数据文件位于 `/opt/growth-dashboard/data/dashboarddb.mv.db`。
适合个人/小团队使用。定期备份该文件即可。

### 方案 B：MySQL（生产推荐）

```bash
sudo apt install -y mysql-server    # 或 dnf install mysql-server
sudo mysql
```

```sql
CREATE DATABASE dashboard DEFAULT CHARSET utf8mb4;
CREATE USER 'dashboard'@'localhost' IDENTIFIED BY '换成强密码';
GRANT ALL PRIVILEGES ON dashboard.* TO 'dashboard'@'localhost';
FLUSH PRIVILEGES;
```

表结构由应用首次启动时自动创建，初始数据（演示账号、能力维度等）自动播种。

## 4. 环境变量配置

创建 `/opt/growth-dashboard/app.env`（`sudo chmod 600`，仅 root 可读）：

```ini
# 数据库：H2 方案注释掉下面四行即可
DB_URL=jdbc:mysql://localhost:3306/dashboard?useUnicode=true&characterEncoding=utf8&serverTimezone=Asia/Shanghai
DB_DRIVER=com.mysql.cj.jdbc.Driver
DB_USER=dashboard
DB_PASSWORD=换成强密码

# AI 服务（可选，不配置则使用内置规则引擎）
AI_BASE_URL=https://api.deepseek.com/v1
AI_API_KEY=sk-你的密钥
AI_MODEL=deepseek-chat

# 端口（配合 Nginx 反代保持 7100 即可）
PORT=7100
```

## 5. systemd 后台运行

将本项目 `deploy/growth-dashboard.service` 复制为 `/etc/systemd/system/growth-dashboard.service`，然后：

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now growth-dashboard
sudo systemctl status growth-dashboard    # 确认 active (running)
journalctl -u growth-dashboard -f         # 查看实时日志
```

## 6. Nginx 反向代理 + HTTPS

### 6.1 反向代理

将 `deploy/nginx.conf` 中的 `your-domain.com` 替换为你的域名，复制为
`/etc/nginx/sites-available/growth-dashboard`，然后：

```bash
sudo ln -s /etc/nginx/sites-available/growth-dashboard /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

### 6.2 HTTPS（Let's Encrypt 免费证书）

```bash
sudo apt install -y certbot python3-certbot-nginx
sudo certbot --nginx -d your-domain.com
# certbot 会自动改 Nginx 配置并设置证书自动续期
sudo certbot renew --dry-run   # 验证自动续期
```

## 7. 防火墙放行

```bash
# Ubuntu (ufw)
sudo ufw allow 80,443/tcp && sudo ufw reload
# 应用端口 7100 仅监听本机即可，无需对外放行
```

云控制台的安全组同样需要放行 80/443。

## 8. 验证上线

1. `curl http://127.0.0.1:7100/api/auth/login` 返回 4xx/405 即应用正常（说明服务在跑）
2. 浏览器访问 `https://your-domain.com`，应出现登录页
3. 用 admin / admin123 登录后**立即在「账号管理」中重置管理员密码**，并删除或改密其他演示账号

## 9. 日常运维

```bash
# 升级：上传新 jar 后重启
sudo systemctl restart growth-dashboard

# 备份（H2）：备份整个 data 目录
sudo systemctl stop growth-dashboard
tar czf dashboard-backup-$(date +%F).tar.gz -C /opt/growth-dashboard data
sudo systemctl start growth-dashboard

# 备份（MySQL）：
mysqldump -u dashboard -p dashboard > dashboard-$(date +%F).sql

# 日志排查
journalctl -u growth-dashboard --since "1 hour ago"
```
